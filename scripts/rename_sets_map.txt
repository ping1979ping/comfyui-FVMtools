# rename_sets_map.txt — DRAFT, edit freely before running scripts/rename_sets.py
#
# Purpose: directory names are read back mechanically ("_" -> " ") by the JB
# `sentences` output format:
#
#   location:  The scene takes place indoors, it is a <category>, namely the <leaf>.
#   outfit:    The outfit is a <category> look, in the <leaf> style.
#              (leaf "general" -> "The outfit is a <category> look.")
#
# So every category must be a singular noun phrase that fits "it is a ...",
# every location leaf a noun phrase that fits "namely the ...", and no
# country/state codes (_us, _de, _pa) or trailing qualifiers (_inside,
# _interior, _plain, _busy, _private) may remain.
#
# Rule syntax:  old_path => new_path      (POSIX, relative to location_lists/ or
#               outfit_lists/ — the first segment decides which root)
#   2 segments  = category rule, moves every set under it
#   3 segments  = set rule, wins over the category rule for that set
#   Sets not mentioned keep their name. Lines starting with # are comments.
#   Delete a line to keep the old name. Change the right side to pick a
#   different name.
